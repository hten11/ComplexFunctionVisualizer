[1. 기본 원칙]
- 수학적 계산과 시각화 분리
- 2D와 3D가 동일한 계산 엔진 사용
- 수학적으로 정확한 계산을 우선 구현
- 시각화는 유한한 표본을 이용해 근사

[2. 복소함수 입력]
- 기본 함수 선택 및 함수식 직접 입력 지원
- 기본 함수: z, z², z³, 1/z
- 직접 입력 예시: z**2 + 1, sin(z), exp(z)
- 기본 함수 선택 시 함수식 자동 입력
- 기존 수치 계산 및 기호 계산 엔진과 연결
- 허용된 수학 연산만 처리하는 안전한 파서 사용

[3. 정의역 입력]
- 방정식과 부등식으로 정의역 직접 입력
- x = Re(z), y = Im(z) 기준
- 원판, 원, 정사각형, 고리 영역 등 표현 가능
- 정의역 조건을 만족하는 점만 유효하게 처리
- 등식 판정에는 부동소수점 오차 고려

[4. 2D 화면 표시]
- 복소평면 두 개를 나란히 표시
- 왼쪽: 정의역 평면
- 오른쪽: 공역 평면
- 입력점 z와 대응점 f(z) 표시
- 입력점을 마우스로 드래그
- 드래그에 따라 출력점 실시간 이동
- 출력점의 이동 경로를 자취로 표시
- 정의역 밖으로 입력점이 이동하지 않도록 제한
- 두 평면의 대응점은 선택 상태를 공유

[5. 3D 화면 표시]
- 두 복소평면을 하나의 3D 공간에 배치
- 두 평면은 고정된 간격으로 배치
- 입력점과 출력점을 대응선으로 연결
- 정의역의 경계와 내부 격자 표시
- 변환된 영역의 경계와 내부 격자 표시
- 일정한 간격으로 대응선 표본 선택
- 도형 격자 간격과 대응선 간격은 별도 설정
- 특이점이나 불연속 구간을 무분별하게 연결하지 않음

[6. 계산 및 대응 처리]
- 함수값 계산
- 정의역 포함 여부 판정
- 정의역 표본 생성
- 유효한 표본에 함수 적용
- 정의되지 않는 점과 무한대가 되는 점 제외
- 2D와 3D에서 동일한 계산 결과 사용

[7. 수학적 예외 처리]
- 1/z에서 z = 0 처리
- 복소 로그와 제곱근의 가지(branch) 문제 고려
- 함수의 특이점 처리
- 잘못된 함수식과 정의역 식 거부
- 계산 오류 및 유효하지 않은 값 처리

[8. 검증할 함수와 영역]
- f(z) = z : 원판
- f(z) = z² : 단위원판
- f(z) = z² : 정사각형
- f(z) = 1/z : 1 ≤ |z| ≤ 2
- f(z) = e^z : 직사각형

[9. 개발 순서]
- 복소함수 입력 기능
- 정의역 파서
- 함수 대응 계산 엔진
- 2D 대응점 시각화
- 2D 드래그 및 자취
- 2D 영역 변환
- 3D 평면 및 대응선 시각화
- 전체 GUI 통합
