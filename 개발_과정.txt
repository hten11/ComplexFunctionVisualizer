[복소평면 함수 대응 프로그램 - 전체 개발 순서]

0단계. To do, 개발 과정, 파일 구조과 역할, 프로그램의 목표 정리

1단계. 기본 복소수 계산기
- complex_parser.py
- numeric_engine.py
- symbolic_engine.py
- 기본 계산 테스트

2단계. 복소함수 입력 기능
- function_parser.py
- 기본 함수 선택
- 사용자 함수식 입력
- 기존 계산 엔진과 연결

3단계. 정의역 및 함수 대응 계산
- domain_parser.py
- math_engine.py
- 정의역 조건 판정
- 입력점과 함수값 대응 계산

4단계. 2D 시각화
- view_2d.py
- 두 복소평면 표시
- 입력점과 대응점 표시
- 드래그 및 출력점 자취

5단계. 3D 시각화
- view_3d.py
- 두 복소평면의 3D 배치
- 대응선 표시
- 정의역과 치역의 도형 표현

6단계. 전체 프로그램 통합
- main.py
- 사용자 인터페이스 연결
- 설정 및 오류 처리
- 전체 기능 테스트
